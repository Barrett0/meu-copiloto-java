
# 🚀 Meu Copiloto Java

Copiloto personalizado baseado em prompts para auxiliar no desenvolvimento com Java e Spring Boot.

## 🧠 Sobre o projeto

Este projeto contém um conjunto de prompts organizados para simular um copiloto de programação, ajudando desenvolvedores iniciantes a:

- Criar APIs REST
- Desenvolver CRUDs
- Entender conceitos de backend
- Aprender Java e Spring Boot na prática

---

## ⚙️ Tecnologias

- Java 17
- Spring Boot
- Maven
- JUnit
- MySQL

---

## 🤖 Modos do Copiloto

### 🔧 Agent
Gera código completo pronto para uso.

### ❓ Ask
Responde dúvidas e explica código.

### 📚 Study
Ensina conceitos de forma didática.

### 🧠 Plan
Ajuda a planejar projetos passo a passo.

---

## 🚀 Como usar

1. Copie o conteúdo de um dos arquivos de prompt
2. Cole no ChatGPT
3. Faça sua pergunta ou peça um projeto

Exemplo:
"Crie uma API de cadastro de clientes em Java com Spring Boot"



## 🎯 Objetivo

Ajudar desenvolvedores iniciantes a evoluir em Java e se preparar para o mercado de trabalho.
